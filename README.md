# Arina Mangla — Online Portfolio (Version 11)

A responsive, editable website made with HTML, CSS and JavaScript. It requires no build tools.

## View locally

Unzip the archive and open `engineering-portfolio/index.html` in a web browser. Keep the full `engineering-portfolio` folder together so that photos, videos and PDFs load correctly.

## Edit and republish

- Edit the project titles, summaries and card imagery in `data.js`.
- Edit the detailed project content in the corresponding HTML pages.
- Edit colours, typography and spacing in `styles.css`.
- Add or replace photos and videos in `assets/`, updating their paths in the page or `site.js`.
- To update an existing published version, redeploy the entire `engineering-portfolio` folder to the same hosting project.

## Before making the site public

Please review photographs of other people and obtain permission to publish them; verify your written claims and awards; and check PDFs for personal information. The CREST prototype demonstrates test alerts only; it does not directly contact emergency services. The separate code appendix is deliberately excluded because it contains account and Wi-Fi credentials.
